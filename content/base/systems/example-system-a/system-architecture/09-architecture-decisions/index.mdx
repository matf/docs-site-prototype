## Recording a decision

An ADR is a custom page. Add a file to
`docs/systems/example-system-a/09-architecture-decisions/` following the naming pattern
`adr-NNNN-short-title.mdx`, give it a `sidebar_position`, and add a row to the table above. Each
ADR names the arc42 sections and components it affects, so the decision and its consequences stay
connected.

The system glossary in [Example System A — 12. Glossary](/systems/example-system-a/system-architecture/glossary/)
applies. Only component-specific terms are listed here.

The names in the code are extracted automatically into
[Domain Model Terms](/systems/example-system-a/components/example-component-b/system-architecture/glossary/domain-model-terms/). This page
covers the words that are easy to get wrong.

## Terms used carefully

| Term | Note |
| --- | --- |
| **Score** | A number without meaning on its own. Only the **band** is a decision. Officers are shown the band and the fired rules, never the raw score. |
| **Invalidated** | A case whose revision was superseded. Invalidated cases keep their decision for the record; they are not deleted. |
| **Recalculation** | Produces a *new* decision with a new identifier. It never overwrites an existing one. |

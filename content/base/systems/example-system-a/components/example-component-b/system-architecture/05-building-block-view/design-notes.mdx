## Why this structure

The same hexagonal structure as every component in this system, with one addition worth noticing:
the **Rule Set Cache** and the **Model Cache** are separate building blocks, because rule sets and
models have different lifecycles — rules change weekly, models quarterly.

## Why the domain is pure

The `Scoring Domain` block has no outgoing dependencies at all. Every input — rule set version,
model version, declaration content, history features — is passed in, and the same inputs always
produce the same band. That is what makes a three-year-old decision reproducible, and it is why
the build fails if the domain touches the clock.

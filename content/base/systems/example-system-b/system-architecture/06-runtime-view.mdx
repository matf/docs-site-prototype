## Scenario — measurement goes stale

```mermaid
flowchart LR
  classDef step fill:#f6f7f9,stroke:#9aa4ae,color:#12161a
  classDef warn fill:#fdf4e5,stroke:#8a5a00,color:#12161a

  M["Last measurement received"]:::step
  A{"Older than<br/>10 minutes?"}:::step
  S["Show the figure"]:::step
  W["Mark as 'no current data'<br/>and keep the last time shown"]:::warn

  M --> A
  A -->|no| S
  A -->|yes| W
```

Showing "no current data" rather than the last known value is the first quality goal in action.

# 12. Glossary

<DocHeader structure="system-architecture" system="example-system-b" section="glossary"
  custom={{owner: 'Team Beta — Public Information Services (fictional)', lastReviewed: '2026-07-11'}} />

| Term | Meaning |
| --- | --- |
| **Waiting time** | Estimated time from joining the queue to passing the control point, derived from lane sensor measurements. Never measured by this system. |
| **Current** | Backed by a measurement no older than 10 minutes. Anything older is "no current data". |
| **Broadcast** | A manually triggered operational notification, as opposed to an automatic status change. |
| **Channel** | A delivery route: e-mail, push or the public status page. |
| **Subscription** | A channel address plus a language. No further personal data — constraint B-3. |

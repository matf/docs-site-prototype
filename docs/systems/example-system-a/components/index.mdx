# Components of Example System A

Each component below is documented with the same twelve arc42 sections as the system itself.
`Components` is a sibling of the system's arc42 sections, not a sub-tree of
[5. Building Block View](/systems/example-system-a/building-block-view/) — the building block view
*describes and links* the components, the documentation itself lives here.

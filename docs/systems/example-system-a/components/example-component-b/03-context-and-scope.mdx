## What the diagram does not say

- **The Declarant History Store is read-only and feature-level.** It never returns identity
  attributes — constraint CB-2 in
  [2. Architecture Constraints](/systems/example-system-a/components/example-component-b/architecture-constraints/).
  Fairness review depends on this boundary holding.
- **The Model Registry is a hard dependency at case start and a soft one afterwards.** Versions
  are cached, so a registry outage does not stop assessment of cases that use an already-loaded
  version; only a newly published version cannot be picked up.
- **`OrderInspection` is a command, not an event.** It is the only imperative message this
  component sends, and it goes to a system that may refuse it.

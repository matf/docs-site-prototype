| `RiskCase` | The aggregate root. One case per declaration revision. |
| `Decision` | An immutable record: score, band, fired rules, rule set version, model version. |
| `band` | `low`, `elevated` or `high`. The decision that downstream systems act on. |
| `firedRules[]` | Identifiers of the rules that contributed to the score. The officer-facing explanation. |
| `ruleSetVersion` | Immutable version of the rule set, e.g. `2026.07`. |
| `modelVersion` | Immutable version of the scoring model, e.g. `v14`. |
| `fallback` | Flag marking a decision taken without the scoring model. |
| `shadow` | Flag marking a decision computed for evaluation only; never published. |

## Terms used carefully

| Term | Note |
| --- | --- |
| **Score** | A number without meaning on its own. Only the **band** is a decision. Officers are shown the band and the fired rules, never the raw score. |
| **Invalidated** | A case whose revision was superseded. Invalidated cases keep their decision for the record; they are not deleted. |
| **Recalculation** | Produces a *new* decision with a new identifier. It never overwrites an existing one. |

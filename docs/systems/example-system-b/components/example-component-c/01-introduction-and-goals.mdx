# 1. Introduction and Goals

<DocHeader system="example-system-b" component="example-component-c" section="introduction-and-goals"
  custom={{owner: 'Team Beta — Channels Squad (fictional)', lastReviewed: '2026-07-09'}} />

## Task

Deliver a notification to every opted-in channel, in the subscriber's language, and record what
happened. It decides nothing about content — it receives a finished, translated notification and
delivers it.

## Quality goals

| Priority | Goal | Scenario |
| --- | --- | --- |
| 1 | **Reach** | 95 % of notifications delivered within two minutes of the request. |
| 2 | **No duplicate delivery** | A redelivered request does not send a second message to the same subscriber. |
| 3 | **Honest delivery records** | A delivery record is only written when the provider confirmed acceptance. |

## Stakeholders

| Role | Expectation |
| --- | --- |
| Subscriber | One message per event, in the right language |
| Operations | Failures are visible and actionable |
| Communications | Delivery statistics per channel |

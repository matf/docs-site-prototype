| --- | --- | --- | --- | --- |
| C-ADR-0001 | A delivery attempt record per (notification, subscriber, channel) | Accepted | 2026-03-24 | Makes duplicate suppression a database constraint rather than application logic. |
| C-ADR-0002 | Rate-aware batching with a token bucket below the provider limit | Accepted | 2026-04-02 | Bursting gets the whole sender throttled; a slightly slower fan-out is the cheaper failure. |
| C-ADR-0003 | The component never composes or translates content | Accepted | 2026-04-02 | Translation completeness is a publication gate upstream (B-ADR-0002); splitting it would create two places to get it wrong. |

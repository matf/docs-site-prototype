# 2. Architecture Constraints

<DocHeader system="example-system-b" component="example-component-c" section="architecture-constraints" status="custom"
  custom={{owner: 'Team Beta — Channels Squad (fictional)', lastReviewed: '2026-07-09'}} />

All constraints from
[Example System B — 2. Architecture Constraints](/systems/example-system-b/architecture-constraints/)
apply. Component-specific:

| # | Constraint | Reason |
| --- | --- | --- |
| CC-1 | The external e-mail and push provider enforces a send rate limit. | Fan-out must be rate-aware; bursting gets the sender throttled for everyone. |
| CC-2 | Subscription data holds a channel address and a language only. | Constraint B-3 — no further personal data. |
| CC-3 | The component never composes or translates content. | Translation completeness is decided upstream (B-ADR-0002). |

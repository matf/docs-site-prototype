# 7. Deployment View

<DocHeader system="example-system-b" section="deployment-view" status="custom"
  custom={{owner: 'Team Beta with Platform Operations (fictional)', lastReviewed: '2026-07-11'}} />

| Aspect | Value |
| --- | --- |
| Sites | Two Swiss data centres, active/active for the public path |
| Public path | Static pages behind the federal content delivery cache |
| Dynamic path | Container platform, 3 replicas per service |
| Environments | `dev`, `test`, `prod` |
| Deployment | Rolling, health-gated |
| Recovery time objective | 15 minutes for the dynamic path; the public path serves cached pages meanwhile |

The public path is active/active because it is read-only and cacheable — the constraint that
forced warm standby in
[Example System A](/systems/example-system-a/architecture-decisions/adr-0002-hosting-and-data-residency/)
does not apply here.
